# Showcase Checklist

Before adding the project to a résumé:

- [ ] Run the full suite on identifiable hardware.
- [ ] Commit `results.json`, `report.md`, and charts from that hardware.
- [ ] Run and commit a profiler trace summary.
- [ ] Run the graph-break diagnostic and explain the correction in your own words.
- [ ] Run the dynamic-shape experiment with repeated lengths.
- [ ] Run the Triton kernel benchmark on a supported CUDA system.
- [ ] Open at least one issue describing an observed limitation or planned improvement.
- [ ] Create a tagged release.
- [ ] Add only measured, reproducible metrics to the résumé.
- [ ] Record one negative or counterintuitive result; this makes the analysis more credible.

Recommended repository topics:

`pytorch`, `torch-compile`, `torchdynamo`, `torchinductor`, `onnxruntime`, `triton`, `ml-systems`, `inference-optimization`, `performance-engineering`
