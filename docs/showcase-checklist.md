# Showcase Checklist

Before adding the project to a résumé:

- [x] Run the full suite on identifiable hardware.
- [x] Commit `results.json`, `report.md`, and charts from that hardware.
- [x] Run and commit a profiler trace summary.
- [x] Run the graph-break diagnostic and explain the correction in your own words.
- [x] Run the dynamic-shape experiment with repeated lengths.
- [ ] Run the Triton kernel benchmark on a supported CUDA system.
- [ ] Open at least one issue describing an observed limitation or planned improvement.
- [ ] Create a tagged release.
- [x] Add only measured, reproducible metrics to the résumé.

Recommended repository topics:

`pytorch`, `torch-compile`, `torchdynamo`, `torchinductor`, `onnxruntime`, `triton`, `ml-systems`, `inference-optimization`, `performance-engineering`
